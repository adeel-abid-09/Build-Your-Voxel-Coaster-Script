# Build Your Voxel Coaster - Auto Build & Automation Script

High-performance Auto Build & Automation script for **Roblox: Build Your Voxel Coaster**.

## Loadstring (Script Link)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/adeel-abid-09/Build-Your-Voxel-Coaster-Script/main/main.lua"))()
```

## Features
- **Auto Build Coasters**: Closed Circuit Loop, Large Oval, Sky Spiral, Speed Runway
- **Continuous Rail Follow**: Lays rails and supports under your feet as you walk or fly
- **Structure Builder**: Flat Platforms (10x10, 20x20, 30x30), Sky Pillars
- **Instant Stunt Spawner**: Loop Rail, Monster Loop, Giant Drop, Corkscrew, Airtime Hills, Cobra Roll
- **Minecart Automation**: Auto Spawn, Auto Mount/Ride, Cart Velocity Booster
- **Auto Rewards**: Auto Claim Daily & Free Cash Playtime Rewards
- **Player & Movement**: Smooth Fly, Noclip, WalkSpeed Slider, JumpPower Slider, Infinite Jump, 24/7 Anti-AFK
- **Monochrome UI**: Pure Midnight Black boxes, crisp White text, Zero emojis, Draggable card and Mobile toggle button
